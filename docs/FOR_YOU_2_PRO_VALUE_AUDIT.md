# For You 2.0 Pro Value Audit

Audit date: 2026-08-13

## Product Roles

- Discover answers “What exists?” It remains the complete free search and filtering surface.
- Journey answers “What am I doing?” It remains the free workspace for saves, applications, deadlines, and progress.
- For You Pro answers “What deserves my attention?” It prioritizes a small safe set and explains the decision using profile, timing, catalog, and Journey context.

## Free

Free currently receives:

- one high-quality personalized preview selected by the same safety pipeline
- concise fit signals
- official opportunity access
- Add to Journey
- a truthful explanation of what Pro adds

Free does not receive the Pro briefing object from the server. Discover and Journey are not degraded.

## Pro

Pro receives:

- the full bounded safe shortlist, up to eight records
- selective Top Picks
- Opportunity Radar for meaningful changes
- Journey-aware “What this adds” context
- documented “Why now” timing
- current opportunity mix
- controlled exploration separated from core picks
- deeper deterministic recommendation explanations
- ongoing learning from account-scoped profile, Journey, and explicit feedback

The difference is intelligence and recurring monitoring, not merely card quantity.

## Recurring Value

The snapshot version changes when the student's profile, Journey, feedback, billing entitlement, or recommendation source signals change. Catalog and rules versions also invalidate stale projections. This means For You can change for justified reasons while remaining stable across ordinary refreshes.

Opportunity Radar makes catalog lifecycle work visible only when it affects a student. The same underlying change architecture can support notifications and future optional digests without creating another event store.

## Honest Boundary

The current safe catalog averages 4.96 recommendations across 250 undergraduate fixtures. This is enough to demonstrate prioritization but not enough to promise a large briefing for every profile. The product therefore uses truthful scarcity:

- sections with no evidence do not render
- Top Picks remain scarce
- no unsafe padding is added
- empty Radar states say the student is caught up
- low-coverage profiles are directed to Discover without implying failure

## Thirty-Second Test

In the equivalent-account browser flow, Free displays one safe recommendation and the premium boundary. Pro displays a briefing headline, selective Top Picks, Opportunity Radar, Journey mix, and deeper reasoning. The distinction is visible without opening a settings screen or reading documentation.

## Remaining Value Risks

- Recommendation-safe catalog breadth is the largest constraint on recurring value.
- Radar needs consistent meaningful changelog data to feel active over time.
- Some opportunity records lack effort and location metadata, reducing explanation depth.
- Product value should be measured by recommendation-to-Journey and application progression, not page views alone.

## Intentionally Not Implemented

- No LLM or generated advice.
- No career coach, roadmap, or motivational copy.
- No Radar navigation tab or duplicate event store.
- No large For You filter system; deeper exploration stays in Discover.
- No fake match percentages, urgency, scarcity, applicant counts, or locked fake records.
- No new onboarding flow; “Tune For You” uses the existing Profile surface.
- No new notification or email types in this sprint.
