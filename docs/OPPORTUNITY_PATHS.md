# Opportunity Paths V1

Opportunity Paths organizes recommendation-safe catalog records around a goal. It does not own opportunity status, dates, application work, or completed history.

## Deferred paths

- **Medicine / Pre-Med:** current recommendation-safe records do not provide enough clinical exposure, service, and medicine-specific summer-program coverage.
- **Law:** public-policy inventory is useful, but standalone legal internships and pre-law programs are too sparse for a distinct Path.
- **Entrepreneurship:** current catalog support is not broad or diverse enough for a trustworthy launch.
- **Consulting:** relevant analytical and career programs remain inside Finance & Business until the catalog supports a distinct Path.

These candidates should launch only after the same coverage audit passes. Paths must not use unsafe legacy inventory to appear complete.

## Mapping contract

- Mapping uses IDs, canonical opportunity types, categories, majors, tags, and career paths.
- Opportunity title and description prose are not mapping inputs.
- One catalog record may belong to multiple Paths.
- Within one Path, a record is assigned to one best-fit section.
- Only records that pass the existing recommendation-safety audit enter current Path inventory.
- Eligibility is evaluated against the existing student context; uncertainty is labeled for review rather than presented as a proven fit.

## State contract

- **Watch** owns passive monitoring.
- **Journey** owns active pursuit.
- **Planner** and **Calendar** own time.
- **Application Command Center** owns application work.
- **Accomplishments** owns completed history.
- Following a Path is only an account-scoped return preference. It never adds an opportunity to Journey or changes a profile goal.
